# Script: What Is Claude Code
**Target Persona:** Beginner/Intermediate dev stuck in copy-paste AI workflows (ChatGPT, Copilot, Cursor)
**Format:** Talking head with screen recording b-roll
**Duration:** 60–90s

---

**[0–3s] HOOK:**
"The difference between Claude and Claude Code is bigger than you think."

*Deliver straight to camera, no setup. Let the contrast do the work.*

---

**[3–12s] PROBLEM / CONTEXT:**
"Most devs using AI are still doing this — open ChatGPT, describe the bug, copy the code, paste it in, run it, it breaks, go back, explain the new error, copy again. Or you've got Copilot autocompleting your lines but you're still driving every single decision yourself. That's not AI doing the work. That's you doing the work with an AI assistant watching."

*B-roll: screen recording of the copy-paste loop — ChatGPT tab, editor tab, switching back and forth.*

---

**[12–35s] SOLUTION / DEMO:**
"Claude Code is different. It runs in your terminal. You type what you want in plain English — 'add auth to this app', 'refactor this module', 'write tests for everything in /api' — and it reads your whole codebase, figures out which files need to change, edits them, runs your commands, and fixes what breaks. You're not pasting anything. You're not telling it which file to look at. It just... does the task."

*B-roll: terminal open, `claude` running — it reads files, edits components, runs tests, all autonomously. Show the actual output scrolling.*

---

**[35–50s] RESULT / PROOF:**
"Same task I used to spend 30 minutes copy-pasting through ChatGPT — Claude Code finished it in under 2 minutes. And I didn't touch my editor once."

*B-roll: side-by-side or before/after. Show the clock if possible. Show the working result — app running, tests passing.*

---

**[50–60s] CTA:**
"It's not a replacement for the chatbot. It's a completely different tool. Install link is in my bio — there's a free tier, zero reason not to try it. Follow for more."

*Back to talking head, keep it casual — not a pitch, just a tip.*
